@page libraries Libraries

As mentioned, this engine isn't built from the ground-up. It uses (mostly) free as in cost libraries. Aside from Steam Audio, all these libraries are available by updating git submodules. 

# Raylib

Cross-platform OpenGL renderer. Handles window and keyboard/mouse input.

https://www.raylib.com/

# Flecs

Entity component system framework and engine. Provides the game architecture and main loop.

https://www.flecs.dev/flecs/

# Jolt Physics

Open source physics engine used also for collision detection.

https://github.com/jrouwe/JoltPhysics

# Imgui

User interface framework. 

https://github.com/ocornut/imgui

# SoLoud

Open source audio framework and default 3D sound environment. Used to play sounds and to generate sound bytes procedurally.

https://solhsa.com/soloud/

# (Optional) Steam Audio

For users that don't mind non-free software and want additional positionally aware spatial audio.

https://github.com/ValveSoftware/steam-audio

# s7 Scheme

Scripting language.

https://ccrma.stanford.edu/software/s7/
