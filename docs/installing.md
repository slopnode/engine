As this engine is a work in progress, this page will be updated as new distribution methods are supported. 

This engine has only been tested so far on 64-bit platforms.

# From source

The source code is designed to be easy to clone, compile, and to install like this. For instructions on compilation see @ref compiling. It is cross-platform and be compiled on major platforms. 

# Linux distributions

## Arch Linux

[AUR](https://aur.archlinux.org/packages/slopengine) package of latest release is available as `slopengine`. 

As dependencies are included as vendored libraries, you don't need to use an AUR helper to fetch additional AUR dependencies. You can copy the PKGBUILD file and run `makepkg -si`.
